# Ferma Smart (artifact, versioni 2)
Aplikacion i vetëm në një skedar HTML (shqip): parcela, detyra, vëzhgime, financa, moti, plus skedat BioBes (Qarkullimi, Kultivime, Fletë vjelje, Magazina, Kartela) me PDF A4.
U publikua si artifact në Claude me aftësitë `db` (ruajtje) dhe `downloads` (shkarkim). Hapet edhe lokalisht në shfletues, por ruajtja dhe shkarkimi i PDF kërkojnë ambientin e artifact-it. Është prototip, jo aplikacioni prodhues; aplikacioni prodhues është në dosjen kryesore.
